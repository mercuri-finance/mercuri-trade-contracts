# Separate Mercurifi Trade contracts repository — Claude

This is a separate, private Git repository: Trade's contract set, apart from Launch's. Launch's deployed contracts live in `lib/mercuri-launch-contracts` (a pinned submodule) and the public `contracts/launch/deployments/` records; never change them here, and flag any Trade need for them to the owner as a live-contract change. Trade has no deployed contract yet; the filler and validator candidates have their evidence in `docs/reports/2026-10-02-order-filler-release.md`. Run `bash script/check-contracts.sh` for a candidate change, and keep `lib/uniswapx` and `lib/universal-router` unchanged upstream closures (`python3 script/check-trade-sources.py`); a new pin is recorded in `lib-versions.md`. Before any commit, push, PR or issue, follow the identity gate in `../../docs/agents/release.md`: login, author, committer and HTTPS push transport must all be `mercurifinance`, with no AI `Co-authored-by` trailer. Local builds and tests do not authorize a broadcast, upgrade, Safe or governance action, or deployment record. Never read `.env` or disclose signer material. Use the workspace `.claude/skills/mercuri-contract-assurance/` for a contract review.
